Drag a line from a natural data element to a musical element to map them together. Click the ring below the connected element to open the slider. The slider controls how strongly that data element affects the musical element. 0% has no effect, 100% is a normal effect, and over 100% is an exaggerated effect. Click the green check to save the slider and close it out, and click the red ‘x’ to disconnect completely. You can map multiple natural data elements to a musical element and individual natural data elements to multiple musical elements.
